# Portfolio v3.0.0

`v3.0.0` is the major portfolio refresh for Kartik R. Hirijaganer. It updates the public portfolio around AI engineering, software engineering, technical leadership, and production systems work in healthcare and data platforms.

Live site: [kartik-hirijaganer.github.io/portfolio](https://kartik-hirijaganer.github.io/portfolio/)

## What Changed

| Area | Update |
|---|---|
| Positioning | Reframed the portfolio around AI Engineer, Software Engineer, and Technical Lead opportunities |
| Experience | Added Premier Health Group Technical Lead role and refreshed career timeline |
| Projects | Reordered the portfolio to lead with LLM, agentic AI, and production AI work |

| New project | Added Executive Pay Analysis, a Datathon-winning machine learning project |
| UX | Added section-by-section skeleton loading overlays |
| Maintenance | Fixed resume path, stale copy, typo issues, footer branding, and navigation anchors |
| Deployment | GitHub Pages workflow now publishes only `index.html` and `assets/` |

## Why This Release Matters

This release turns the portfolio from a template-backed project list into a stronger professional signal:

- It leads with current Technical Lead experience.
- It makes production AI and LLM systems the first visible story.
- It shows measurable outcomes across healthcare, data engineering, cloud systems, and full-stack delivery.
- It improves perceived load quality without adding a build system or runtime dependency.

## How To Verify

Run locally:

```bash
python3 -m http.server 8000
```

Open:

```text
http://localhost:8000
```

Check:

- Resume download opens `assets/pdf/Kartik-Hirijaganer_Resume.pdf`.
- Portfolio filters work and keep the masonry layout stable.
- Certificate carousel moves correctly.
- Skeleton loaders appear briefly, then fade without layout shift.
- Navigation dropdown anchors jump to the correct experience and education entries.
- Contact form opens the intended Gmail draft flow.
- Mobile layout works below `768px`.
