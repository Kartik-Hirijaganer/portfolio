# Kartik Hirijaganer — Portfolio

This is my personal portfolio site. It covers my professional experience, selected projects, open-source work, skills, education, and certifications. My work is mainly focused on applied AI, healthcare software, backend and data engineering, and technical leadership.

**Live site:** [kartik-hirijaganer.github.io/portfolio](https://kartik-hirijaganer.github.io/portfolio/)

## Running Locally

There is no build step. From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000/).

## Main Files

- `index.html` contains the page content and structure.
- `assets/css/main.css` contains the site styles.
- `assets/js/main.js` contains the interactive behavior.
- `assets/img/` and `assets/pdf/` contain the portfolio media and résumé.
- `.github/workflows/static.yml` deploys the site to GitHub Pages.

## Deployment

GitHub Pages publishes `index.html` and `assets/` from the `main` branch. Changes made on other branches are not live until they are merged.
